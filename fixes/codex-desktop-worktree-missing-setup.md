# Restore missing setup files or dependencies in a Codex worktree

## Symptoms

A command works in the original project but fails in a fresh Codex worktree because a dependency or ignored local configuration file is missing.

## Diagnosis

Run `git rev-parse --show-toplevel` and `git worktree list` in the affected terminal. Compare the worktree with the original checkout. Check whether the missing file is tracked, intentionally ignored, or generated by setup. Use `git check-ignore -- path/to/file` to check the ignore rule.

## Fix

1. For a missing dependency or generated artifact, put the project's existing install or build command in the appropriate platform's Local Environment setup script. Use the package manager and lockfile the repository expects. Select that local environment when creating the worktree. For an existing worktree, run the same reviewed setup manually inside it.
2. For a safe ignored file that Codex should copy into future local managed worktrees, add its exact repository-relative path to a root-level `.worktreeinclude` file. Back up an existing file before editing it. Review what the pattern matches before creating the worktree.
3. Keep credentials out of shared configuration patterns. Use your normal secret provisioning for any credentials the isolated checkout needs. For worktrees created directly with Git, run setup in that checkout because the desktop copy step applies to local Codex-managed worktrees.

## Verify

Create a fresh worktree with the intended local environment. Check the expected files and run the same command that failed in the new checkout.

## Rollback

Revert the setup or include-file edit if it copies too much or changes unrelated commands. Save any work before removing a test worktree.

## Evidence and limits

Git checkouts contain tracked files. Local setup scripts and selected ignored-file copying cover two different gaps. [Codex worktrees](https://learn.chatgpt.com/docs/environments/git-worktrees) · [Local environments](https://learn.chatgpt.com/docs/environments/local-environment)
